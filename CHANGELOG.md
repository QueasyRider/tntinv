# Changelog

## 1.1.0 — Reusable installation package

- Added first-run Setup Guide for fresh databases
- Added non-secret System Check with database migration status
- Added versioned, automatically applied database migrations
- Added in-app administrator username and password rotation
- Added Etsy and Square disconnect/credential clearing controls
- Replaced new-install branding and URLs with generic defaults
- Added Vercel deployment configuration and environment validation
- Added installation, upgrade, backup, security, support, privacy, and acceptable-use documentation

Existing databases with products or saved provider connections are marked as already set up and continue to the dashboard.

## 1.0.0 — Initial production workflow

- Etsy import and local working copies
- Product and bulk editing
- Import Change Review and Fix Center
- Square preview and export
- Images, variants, categories, taxes, and inventory
- Private administrator login
