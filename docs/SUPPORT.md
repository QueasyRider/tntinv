# Support responsibilities

Define these terms in writing before handing an installation to another business:

- Who owns the Vercel, GitHub, database, Etsy, Square, and domain accounts
- Who pays provider and hosting charges
- Support hours and response targets
- Included updates and excluded custom work
- Backup ownership and restore assistance
- How security reports are submitted privately
- What happens when Etsy or Square changes an API
- How service and data are returned or deleted when support ends

For a support request, collect the application version, time of the problem, affected listing ID or Square object ID, the visible error message, and whether the problem can be reproduced. Never request or accept passwords, OAuth tokens, encryption keys, session secrets, or full database exports through ordinary support channels.
